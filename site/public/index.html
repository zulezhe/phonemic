Why PhoneMic

Built for the moment your microphone breaks — or the one you never had

Zero install on the phone

The phone side is a web page served from your desktop app. No App Store, no APK, no account. iOS and Android both work.

Works on any network

Phone on cellular, computer on Wi-Fi? It goes through an encrypted relay. On the same network it silently switches to a ~6 ms direct link.

End-to-end encrypted

Keys are derived from the pairing code and an ECDH handshake. The relay only ever forwards ciphertext it cannot read.

Small and open source

A ~5 MB native app built with Tauri and Rust, MIT licensed. The relay is open source too — self-host it with one Docker command.

Privacy, in plain words

Your voice is the payload, so the design assumes zero trust in every server:

  • Audio is encrypted with AES-256-GCM on your phone and decrypted on your computer. Nothing in between can listen.
  • No account, no analytics, no advertising, no third-party scripts. We never receive your audio.
  • Recordings are not stored anywhere — the stream is live and discarded as it plays.

Questions

More answers in the help section

What is the latency?

About 6 ms round-trip on the same network, 30–120 ms through the cloud relay. It is tuned for voice input and calls, not for music production.

Do I need to install a driver?

Yes — other apps need a virtual input device to select. The macOS app installs BlackHole for you with one click (it asks for your password once). On Windows, install VB-CABLE from the official VB-Audio site; PhoneMic links you there and detects it afterwards.

Does it work when the phone screen locks?

The page keeps the screen awake while streaming, but iOS stops microphone capture when you leave the browser. Keep the page in the foreground for longer sessions — it is designed for dictation-length bursts.

Is my audio uploaded or stored?

No. Audio is end-to-end encrypted and relayed in real time; neither the relay nor we can decrypt it, and nothing is written to disk.

Which phones and browsers are supported?

Any modern browser with microphone access over HTTPS — Safari and Chrome on iOS 15+, Chrome on Android 8+. No companion app is needed.

Do I need an account?

No. There is no sign-up, no login and no license key. Pairing happens by scanning a code from your own computer.

Can I run my own relay?

Yes. The relay ships as a Docker image: cd relay-server && docker compose up -d. Point the desktop app at your instance with one environment variable. See the self-hosting guide in the repository.

Is there a Windows version?

Not publicly yet. The core is cross-platform, and the Windows build is being prepared for the Microsoft Store. It appears on this page as soon as it is available.
