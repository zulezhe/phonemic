Help & support

Setup, troubleshooting and how to reach a human

System requirements

  • Computer — macOS 12 Monterey or later. A Windows build is in preparation.
  • Phone — iOS 15+ with Safari or Chrome, or Android 8+ with Chrome. Any browser that grants microphone access over HTTPS works.
  • Network — both devices need internet access for the cloud relay. On the same Wi-Fi, no internet is required.
  • Permissions — the phone must allow microphone access for the pairing page, and the desktop app needs permission to install the virtual audio driver once.

First-run setup

  1. Open PhoneMic. If the virtual microphone is not installed yet, the app offers to install it — this asks for your macOS password once.
  2. Point your phone camera at the QR code on screen and open the link.
  3. Tap Allow when the browser asks for the microphone.
  4. In the app you want to talk into (Zoom, OBS, a dictation tool…), choose PhoneMic or BlackHole 2ch as the input device.

Troubleshooting

The app shows no input level, or the other app hears nothing

  • Check that the microphone is actually installed: open Audio MIDI Setup and look for BlackHole 2ch in the device list. If it is missing, run the driver installer again from the app.
  • Check the input device selected inside the other application — many apps keep their own override and ignore the system default.
  • In System Settings → Sound → Input, confirm the level meter moves while you speak into the phone.
  • If the meter moves but the app stays silent, the app is listening to a different device — fix it in that app's audio settings.

The phone shows a certificate warning

In local-network mode the desktop app serves the pairing page over HTTPS with a certificate created on your own machine, so browsers cannot verify it against a public authority. That warning is expected.

Tap Advanced → Proceed to continue. The pairing page offers optional steps to install the local certificate authority, which removes the warning for future visits. Only do this for your own computer's certificate.

The QR code link does not open on the phone

  • Make sure the phone and the computer are on the same Wi-Fi network, then try again — the code contains a local address by default.
  • Guest Wi-Fi networks and some routers block communication between devices ("AP isolation"). Use a normal network, or stay on the relay path which works across networks.
  • If the code has expired, press refresh in the app to generate a new one.

Audio cuts out when the phone screen locks

iOS suspends microphone capture when the browser goes to the background or the screen locks. Keep the pairing page in the foreground while you talk. PhoneMic is designed for dictation-length sessions rather than hours of continuous recording.

Latency is high or the audio stutters

  • On the same network, PhoneMic uses a direct link (about 6 ms). If the app reports relay mode on the same Wi-Fi, the direct connection failed — see the previous item about network isolation.
  • Across networks, 30–120 ms is normal and depends on both internet connections.
  • Weak phone signal or a busy Wi-Fi channel is the usual cause of stutter. Moving closer to the access point usually fixes it.

macOS refuses to open the app

Official builds are signed and notarized by Apple. If macOS still blocks it, open System Settings → Privacy & Security and allow the app there. Never download PhoneMic from anywhere except the official release page.

Windows: VB-CABLE will not install

  • Download it only from the official VB-Audio site. The installer needs administrator rights and a restart of the audio service.
  • After installing, restart PhoneMic so it can detect the new device.
  • If Windows blocks the driver signature, check that you installed the 64-bit package for your Windows version.

Uninstalling

Remove the app — drag PhoneMic from Applications to the Bin, then empty it.

Remove the virtual microphone (only if you do not use it for anything else) — delete /Library/Audio/Plug-Ins/HAL/BlackHole2ch.driver and restart your Mac. Other applications may depend on BlackHole, so it is safe to leave it installed.

Remove local settings — delete the app's configuration folder inside ~/Library/Application Support. Nothing is stored anywhere else.

Recording responsibly

PhoneMic is a microphone, not a recording service — it stores nothing. If you record other people with it, laws in many countries require their consent. You are responsible for how you use the audio.
